# Market Lab｜株価シミュレーター

実際の株価データを参考に、仮想資金100万円で売買を体験できる学習用Webアプリです。

## 公開URL
GitHub Pagesを有効にすると、通常は https://mikumats2011-bot.github.io/apps/stock/ で開けます。

## 機能
- 日本株・米国株の株価と5日間チャート表示
- 仮想資金100万円での買い・売り
- 保有株、平均取得価格、評価額、評価損益の表示
- 取引履歴とブラウザ内保存
- リセット機能

## データについて
Yahoo Financeの公開チャート情報をAllOriginsの公開CORSプロキシ経由で取得します。非公式エンドポイント・公開プロキシを使うため、アクセス制限や仕様変更により取得できない場合があります。表示価格は遅延・欠損の可能性があり、投資判断には使用しないでください。

## 注意
これは教育目的のペーパートレードです。実際の注文、証券口座、入出金とは接続されません。手数料・税金・売買スプレッドは計算していません。取引データは利用中のブラウザのlocalStorageに保存されます。
