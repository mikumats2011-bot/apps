# よりみちマップ

行った場所にピンを立てて、自分だけの思い出地図を作る小さなWebアプリです。

## できること
- 地図をタップして場所を登録
- OpenStreetMap / Nominatimで場所を検索して登録
- カフェ・レストラン・おでかけ・その他で分類
- ブラウザ内に保存
- 登録した場所を含む共有リンクを作成
- 現在地へ移動（位置情報の許可が必要）

## 使い方
1. `index.html` をブラウザで開く
2. 地図をタップするか、場所を検索する
3. 名前・カテゴリー・メモを入力して保存
4. 「シェア」で地図リンクを共有

## 公開方法
GitHubリポジトリの **Settings → Pages** で、Build and deployment を **Deploy from a branch**、Branch を **main / (root)** に設定すると公開できます。

## データとプライバシー
登録内容は基本的に利用中のブラウザの localStorage に保存されます。共有リンクには登録した場所の名前・カテゴリー・メモ・座標が含まれるので、共有相手に見せてよい内容だけを登録してください。共有リンクを開いた側の編集は元の地図には反映されません。

地図データは OpenStreetMap、場所検索は Nominatim を利用しています。各サービスの利用ポリシーに従ってください。
